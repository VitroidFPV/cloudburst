# Use qBittorrent as the transfer backend

Cloudburst will control qBittorrent through its Web API instead of implementing or bundling a torrent engine. It will resolve a running local qBittorrent instance and provide a manual connection override when resolution fails. qBittorrent remains authoritative for torrent and engine state, while Cloudburst owns its presentation, connection, and desktop behavior; this keeps the project maintainable for a single primary user without reducing Cloudburst to a browser tab. The initial compatibility floor is qBittorrent 5.2 so the integration can use current authentication and API behavior without carrying older-version branches; compatible later patch and minor releases are not pinned.

Connection profiles are canonical because qBittorrent does not provide a supported discovery protocol. Connection resolution tries the last successful profile, `localhost:8080`, and the address and port from a running process's standard profile before asking for a manual URL; it does not scan arbitrary ports or extract qBittorrent password material. Authentication prefers an API key with username and password as a fallback, stores secrets through the desktop shell's protected credential facility, and does not depend on localhost authentication bypass. When no instance is running, Cloudburst initially offers to start qBittorrent rather than launching it silently.

Cloudburst may save multiple connection profiles but uses only one at a time, and its initial support boundary is local qBittorrent instances. It refuses qBittorrent versions older than 5.2 instead of attempting degraded compatibility. Cloudburst may locate qBittorrent in standard installation locations or use a manually configured executable, but qBittorrent remains independently managed and continues running when Cloudburst quits. If the connection is lost, Cloudburst preserves the last known torrents as visibly stale, retries with bounded backoff, and offers explicit reconnect and start actions rather than showing an empty list or silently relaunching qBittorrent.
