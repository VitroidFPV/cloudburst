# Use Tauri 2 for the desktop shell

Cloudburst will package its generated client-only Nuxt application with Tauri 2 for Windows and Linux. Tauri was chosen over Electron, Wails, and Electrobun because its stable release line and official integrations cover Nuxt, tray behavior, notifications, dialogs, single-instance handling, URL schemes, file associations, protected credentials, and updates without bundling a browser runtime. The Rust core owns qBittorrent HTTP sessions and credentials, connection resolution, and native lifecycle integrations; the Vue application owns product and presentation behavior through a narrow typed boundary.
